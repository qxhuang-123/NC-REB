NC-REB reproducibility release

Includes the four-method experiment code, frozen results, resource protocol and checksums. The planning-input archive contains all retained four-city station records, demand cells and time rows used by the frozen experiments. Extract it at repository root and run python run_experiments.py --check-inputs.

Original observations are attributed to Yu ruotao, DOI 10.6084/m9.figshare.32917595.v1, CC BY 4.0. Code is MIT. Full original SQLite database packaging is complete, with Zenodo upload pending account authorization. Engineering menus and future demand multipliers are planning scenarios.

Relocated code was checked on the complete Shenzhen batch: all 154 returned statuses and costs matched, and 56 feasible plans passed original-graph checks. This validation rerun is excluded from paper timing results.
